# Lemus Studio — Software & Digital Agency

Sitio web y portafolio comercial de alto rendimiento para **Lemus Studio**, agencia boutique de software, diseño de interfaces y soluciones digitales a medida.

## Características
- **Diseño Brutalista & Minimalista:** Tipografía Geist y Hanken Grotesk, micro-interacciones a 60 FPS y sistema visual de alto impacto.
- **Rendimiento Implacable:** Carga instantánea (<1s), optimizado al 100% para dispositivos móviles y SEO Google.
- **Motion Graphics 3D:** Renderizado interactivo en tiempo real con Three.js / WebGL.
- **Modal de Contacto Interactivo:** Cotizador con selección múltiple y generación estructurada de consulta directa a WhatsApp (+502 46141706).
- **Modo Claro / Modo Oscuro:** Adaptabilidad completa de alto contraste y sincronización dinámica.

## Despliegue en Vercel
Este repositorio está listo para desplegarse con cero configuración en Vercel:
1. Conecta el repositorio `josejuliolemus10-star/lemus-studio` en [Vercel](https://vercel.com).
2. Vercel detectará automáticamente `index.html` en la raíz.
3. Haz clic en **Deploy**.
